# Mission (Steps 2–5)

The on-robot executive. It receives the plan from the planner, then repeats for every set:
walk to the AGV, pick one plate, walk to the set position, place the plate. It records each
plate as placed, missed or broken, and scores the run against the success criteria: at least
90 % of plates at their designated positions and none broken.
