      Settings

      Robot link

      Where Send plan and Start mission go. Blank, or unreachable, and the plan downloads as files instead.

      Robot map frame

      Where this room's south-west corner (the map's lower-left pixel) sits in the robot's own map, and the grid it wants. Leave at 0 if the robot's map starts at that corner.

      Hall camera (CCTV)

      Four floor points the camera can see, clicked on its picture, turn its pixels into metres on this plan. Or calibrate on a still:

      A tabletop sits 0.762 m above the floor you calibrate on, so without these every table maps too far out and too big — at 6 m up, 1.45 m out of place.

      Static map for navigation

      Three files: the map, its resolution and origin, and the named service goals. What map_server loads.

      Table and fixture footprints as static obstacles, plus one named goal per cover (T07/cover03). A prior for SLAM to start from, not a substitute for it.

      A layout file holds the room, everything on it, and the traced structure. It is the one that always works.

      Calibrate the camera

      Click four points on the floor, then say where each one is on the plan, in metres from the north-west corner. Room corners are the default; a camera in a corner cannot see the one below it, so use tape marks or table legs it can see instead. Four points fix the mapping, wherever the camera is mounted.
