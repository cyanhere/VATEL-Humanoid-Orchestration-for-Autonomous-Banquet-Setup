# Navigation (Step 3)

Autonomous navigation of the banquet hall by the Unitree R1. Starting from the planner's static
map, the onboard Hesai JT128 lidar maps the real room to find the exact location of each table,
corrects the difference between the plan and the real arrangement, updates the map, and drives
the robot to each set position.

**Target:** the robot reaches at least 80 % of the required workspace.
